# Suma Sree Interiors and Constructions

Website for Suma Sree Interiors and Constructions, a house construction, renovation, and interior design business. The office is in Hanamakonda, Warangal. The work covers Telangana and Andhra Pradesh. Pages are in English and in Telugu under `/te`.

## Stack

- [Next.js](https://nextjs.org) 16 (App Router)
- React 19
- Tailwind CSS 4

## Commands

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run lint
npm run build
npm start
```

## Deploy

The site is hosted on [Vercel](https://vercel.com).

Production: https://sumasreeinteriors.vercel.app/

Canonical links, `sitemap.xml`, `robots.txt`, and share previews use `NEXT_PUBLIC_SITE_URL` when that variable is set. Otherwise they use the production address above.
